ZEN ACADEMY WEBSITE (Beispielprojekt) / SAMPLE PROJECT

DEUTSCH
- index.html: neue Startseite (Deutsch/Englisch, Sprachumschalter oben rechts)
- woerterbuch.html: verbesserte Seite "Spirituelles Woerterbuch"
- assets/img/: Logo und Fotos (WebP)
So geht es: Ordner entpacken und index.html im Browser oeffnen. Zum Veroeffentlichen den ganzen Ordner auf einen Webspace hochladen.
Bilder austauschen: Dateien in assets/img/ mit gleichem Namen ersetzen.
Hinweis: Der Newsletter-Button im Woerterbuch ist nur eine Vorschau und muss mit dem Newsletter-Tool verbunden werden.

ENGLISH
- index.html: new home page (German/English, language switch top right)
- woerterbuch.html: improved "Spiritual glossary" page
- assets/img/: logo and photos (WebP)
How to use: unzip the folder and open index.html in a browser. To publish, upload the whole folder to a web host.
To swap images, replace the files in assets/img/ keeping the same names.
Note: the newsletter button on the glossary page is a preview only and must be connected to the real newsletter tool.
